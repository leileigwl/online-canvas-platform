# FlowCanvas｜详细产品需求文档（PRD）

> 本文档为 [`docs/PRODUCT.md`](../PRODUCT.md) 的细节展开版，记录重构与上线版的完整页面需求、核心业务闭环、BYOK 生图与多 Agent 规范及验收标准。

---

## 1. 产品定位与上线目标

- **产品名称**：FlowCanvas —— 在线 AI 无限画布与视觉创作工作台
- **上线部署形态**：Web SPA（React 19 + Konva）+ FastAPI + ARQ Worker + PostgreSQL 18 + Redis 7 + MinIO，通过 Docker Compose + Caddy（或 1Panel Nginx 反代）部署于自有云服务器并绑定公网 HTTPS 域名。
- **商业与开源定位**：开源可自托管（MIT）；公网站点默认采用 **BYOK（用户自带模型与生图密钥）**，同时支持管理员通过 CLI 种子脚本维护预置演示账号用于项目展示与面试。
- **解决的核心痛点**：
  1. 创作者在零散对话窗口与本地文件夹间反复搬运参考图和生成图，缺少统一空间编排视角；
  2. 传统网页直接调外部生图/大模型易导致浏览器超时、页面卡死或 API 密钥泄漏；
  3. 让 AI 直接改写画布容易覆盖用户手工修改，缺少安全边界、预览确认与整批回滚机制。

## 2. 用户角色与业务闭环

### 2.1 首页流程、未登录引导与开箱体验
- **用户名密码体系**：唯一用户名 + 密码注册/登录、登录后修改密码、注销账户；不采集邮箱，不做邮箱找回。
- **首页直接创作与空白画布分流**：
  - 首页创作区支持输入提示词、**上传参考图片**并配置 **AI 生图画面配比（比例、分辨率、模型等）**，同时提供「新建空白画布」（进入完全空白画布）与「生成并进入画布」双路径。
  - **未登录引导**：未登录时「我的画布空间」与「素材库」不展示假数据，明确引导登录；若未登录访客在首页输入了提示词、参考图或配比后发起创作，前端暂存参数并引导至登录页，登录成功后自动建画布并带入执行。
- **演示账号与默认引导**：新注册用户自动获得 1 张引导示例画布；提供 `seed_demo` CLI 脚本一键维护面试演示账号。

### 2.2 两条核心 AI 创作闭环

```text
路径 A（直接生图 / AI 改图 → 自动上画布）
  用户在首页或画布底部选择「直接生图 / 改图」模式，输入提示词、设定画面配比并可选参考图
  → 前端在当前视口创建动态“生成中”占位节点，同时 POST /api/agent/runs 提交生图/改图任务
  → 后端校验登录态与参数后入队 Redis/ARQ，秒级返回 run_id
  → 前端建立 SSE 连接监听 /api/agent/runs/{id}/events（无需打开右侧 Agent 面板）
  → Worker 解密用户生图 BYOK 配置（OpenAI 兼容 / 百炼 / 硅基流动）调用生图或改图接口
  → 图片校验后写入 MinIO 私有存储（assets 表），SSE 推送完成事件并直接替换为画布真实图片节点

路径 B（创意与画布统一 AI Agent → 流式思考 + 工具卡片 + 提案确认）
  用户在画布底部选择「AI Agent」模式并下达复杂目标（如多步改图迭代、素材网格整理、视觉说明拆解）
  → 右侧可折叠 Agent 抽屉打开，经 SSE 实时流式展示可折叠「思考过程 (Thinking)」与「工具调用卡」
  → Worker 通过 LangGraph 编排工具调用（generate_image / edit_image / add_note / move_object / resize_object / align_objects / add_shape，无 RAG 切分），受每运行预算控制
  → 生成类结果落入画布；画布排版/属性改动形成待审阅提案，由用户预览点击「应用到画布」后校验 base_revision 写库并支持整批撤销
```

## 3. 页面架构（暖象牙美术馆浅色工作台）

> 严格执行原型门控：**必须先确认 [`docs/02-design/prototypes/flowcanvas-prototype.html`](../02-design/prototypes/flowcanvas-prototype.html) 的交互原型，再改动 `apps/web/` 代码。**

| 页面 | 路由 | 核心结构与关键交互 |
|---|---|---|
| **首页 / 画布库** | `/` | 顶部居中磨砂白导航（我的画布 / 素材库 / 模型设置 / 账户）；中部创作卡片支持上传 0/1/2+ 张参考图（按张数动态切换生图配比参数）、选择「直接生图」或「AI Agent」，并提供「新建空白画布」；下方我的画布空间未登录时引导登录，登录后展示云端画布卡片。 |
| **无限画布工作台** | `/canvas/:canvasId` | 全屏 `100vw × 100vh` 暖象牙微点阵（`#F6F5F2`）Konva 画布；顶部居中单一磨砂白胶囊直达「画布库 / 素材库 / 设置」、可点击直接重命名画布标题、同步版本号、缩放与自适应视图、精简历史版本、**一键导出 PNG**、`AI Agent` 开关，右上角显示紧凑账户入口；左侧极细竖排线性 SVG 工具胶囊（悬停显示 PS 快捷键：`选择 V` / `抓手 H` / `撤销 Ctrl+Z` / `重做` / `文字 T` / `画笔 B` / `局部对齐` / `上传` / `删除 Del`）；右下角常驻可折叠全局小地图（Minimap）；左右抽屉均可关闭；右侧 Agent 抽屉展示可折叠 Thinking 思考流、结构化工具调用卡与提案应用/撤销；底部居中悬浮创作胶囊（按 0/1/2+ 参考图动态变化参数，支持一键清空参考）。 |
| **我的素材库** | `/assets` | 私有图片网格、拖拽/多图上传（12 MiB / 100 MP）、名称搜索、收藏筛选、单张或批量插入指定画布、删除整理；未登录自动引导登录。 |
| **模型与生图设置** | `/settings/agent` | 双板块 BYOK 配置：① **语言模型配置**（服务商预设、HTTPS Base URL、加密 Key、默认模型及四角色独立模型映射、连通测试）；② **AI 生图/改图服务配置**（OpenAI 兼容 / 百炼 / 硅基流动协议、生图与改图模型 ID、HTTPS Base URL、加密 Key、连通测试）。 |
| **登录 / 注册 / 账户** | `/login` `/register` `/account` | 登录/注册采用独立居中极简暖象牙卡片（无顶部冗余胶囊导航，仅保留左上角返回首页入口）；登录后支持修改密码与账户注销。 |

## 4. 功能与安全红线需求

1. **乐观并发锁、流畅拖动与 IndexedDB 草稿保护**：
   - 画布修改（自动保存与提案应用）均携带 `base_revision`；若服务端版本已推进返回 `409`，前端弹窗提供「使用本地草稿覆盖」或「载入云端版本」。
   - Konva 节点拖动使用独立 `dragLayer` 且拖动帧内禁止触发 React `setState`；未同步草稿与本地撤销栈异步写入浏览器 **IndexedDB（500ms 防抖）**，断网或刷新后自动恢复并退避重传，同时支持从 `canvas_versions` 恢复任意历史版本。
2. **多用户数据隔离与密钥保护**：
   - 项目、画布、素材、Agent 运行、模型配置全部强制校验 `owner_id == current_user.id`。
   - 语言模型与生图模型 API Key 均经服务端加密保存，响应只返回 `configured: true` 及脱敏状态，绝不回传明文。
   - 所有自定义 `base_url` 必须通过 `validate_public_https_url` 解析校验，阻断内网/本机探测（SSRF）。
3. **进程崩溃自愈与预算上限**：
   - LangGraph 状态检查点写入 PostgreSQL；Worker 被强杀重启后，ARQ 重派可从已完成节点续跑，同时按条件更新原子扣减每运行调用次数上限（默认 12 次），防止死循环超额消耗。
