# 在线无限画布平台 MVP PRD

> 状态：需求与产品设计基线 v1.1，2026-10-29。MVP 按单用户编辑设计，不含多人同时编辑。

## 1. 产品目标和用户

为个人创作者提供跨会话保存的在线无限画布，并用多个专业 Agent 协助整理素材、规划和执行视觉创作。

目标用户是需要整理图片、构思视觉方案、摆放简单画面并希望通过 Agent 减少重复操作的个人创作者。

## 2. 信息架构

1. 用户名注册、登录、登出和账户安全设置；不收集邮箱。
2. 项目首页：我的项目、最近访问、创建项目。
3. 无限画布：画布工作区、顶部项目栏、左侧素材/图层、顶部固定的选择/平移/撤销/重做工具栏、右侧 Agent 流程/已选图片面板、底部紧凑目标输入栏。
4. Agent 设置：模型连接、Agent 角色、角色对应模型。
5. 账户设置：资料、安全和注销。

## 3. 用户故事

### 账号与个人项目

1. 用户能以唯一用户名和密码注册、登录和登出。
2. 用户能登录后修改密码、注销账户；MVP 不提供邮箱找回或忘记密码恢复。
3. 用户创建、查看、重命名和删除自己的项目与画布。
4. 用户只能读取和修改自己拥有的项目、画布、素材和 Agent 配置。

### 无限画布

5. 用户可在没有固定页面边缘的二维空间平移、缩放、选择、拖动和变换对象。
6. 用户可添加图片、文字和基础形状，调整图层顺序、复制/删除并撤销/重做。
7. 系统自动保存；重新打开后恢复元素、视口和可恢复版本。
8. 多个浏览器标签页或设备出现旧 revision 时，系统提示冲突并保护较新的已保存版本。

### 多 Agent 自主协作

9. 用户可配置 Coordinator 和专业 Agent 角色，并为每个角色选择已保存的 OpenAI 兼容模型配置。
10. 用户在画布底部描述创作目标；Coordinator 生成任务图，按依赖委派 Planner、Canvas Editor、Reviewer。右侧 Agent 面板展示执行过程、结果审阅和已选参考图片。
11. 互不依赖的子任务可并行；依赖任务和画布写入按顺序执行，所有子任务状态、输出、错误都可查看。
12. 用户可取消运行、重试失败任务；重试不重复已成功的副作用。
13. 删除等高影响工具须用户确认；拒绝后相关下游任务停止。
14. Agent 画布修改以操作批次预览；用户接受后写入个人画布，且操作可追溯、可撤销。
15. 用户点击画布图片时，图片自动加入右侧已选参考图列表和底部输入栏；导入图片放到画布并加入底部参考图。创作目标从画布底部提交，右侧不提供第二个输入框或素材添加弹层。
16. 用户导入的图片和 Agent 生成的图片先作为临时内容展示；用户点击“保存到资产”后才加入个人素材库。

右侧 Agent 面板只展示已提交的目标、执行进度、输出审阅和已选参考图片；创作目标从画布底部紧凑栏提交。点击画布图片会自动加入参考图，顶栏导入的图片放在画布上并加入底部输入栏。底部参数浮层包含质量、尺寸、16 倍数对齐、分辨率、宽高比、透明背景和生成张数。当前仅作前端演示，不调用真实生图/改图 API。

多 Agent 用于把用户的创作目标转成安全、可审阅的画布操作。Coordinator 自动组织 Planner、Canvas Editor 和 Reviewer；用户提交一次目标即可，不需要自行选择多个聊天对象。分角色可分别约束计划、画布工具和结果检查，降低模型输出未经验证直接改动数据的风险。

### 图片素材

15. 用户上传私有图片，可搜索/筛选、多选添加到画布或附加给 Agent。
16. 图片文件由对象存储管理；画布只引用素材 ID。

## 4. MVP 范围

### 纳入

- 用户名/密码账户和基础自助管理、个人项目/画布；不收集邮箱。
- 无限画布、图片/文字/基础形状、自动保存、revision 冲突保护和撤销/重做。
- 图片素材库和多 Agent 自主规划/委派/并行/审批/审阅/失败恢复；当前专业 Agent 负责规划、编辑和检查，不调用外部生图/改图 API。
- BYOK OpenAI 兼容模型，按 Agent 角色分配；密钥加密。
- PostgreSQL、Redis/ARQ、MinIO 和一台服务器 Docker Compose 部署。

### 暂不纳入

- 多人同时编辑、项目邀请、共享权限、在线光标和 WebSocket 实时协作。
- 管理员后台、团队/组织空间、计费、公开市场、任意 Agent 插件。
- 提示词库、音频/视频素材、完整移动端编辑体验。

## 5. 关键业务规则

- 用户是自己项目、画布、素材和模型配置的 owner；所有资源 API 检查 user_id 所有权。
- 自动保存使用 base_revision 乐观并发检查；发现旧版本写入时不得静默覆盖。
- Agent 父运行、子任务、依赖、角色、状态、输出、错误、重试和幂等键持久化。
- 工具执行前校验白名单、参数、资源归属、权限、幂等键和画布 revision。
- 模型凭证归属用户，服务端加密；读取配置不返回密钥明文，模型请求服务端进行并校验 SSRF。
- 多 Agent 并行数、循环数、超时和预算有硬上限；不能无限自我委派。

## 6. 产品验收标准

- 未登录用户不能读取项目、画布、素材或 Agent 数据；用户 A 不能读取用户 B 的资源。
- 用户能创建项目并在画布中添加图片/文字/形状，平移和缩放不受固定边界限制。
- 保存成功后刷新可恢复内容；保存失败或 revision 冲突时显示可理解状态并保留本地草稿。
- 多 Agent 运行展示 Coordinator 计划、依赖和并行子任务状态；部分失败时保留成功结果并只重试失败步骤。
- 破坏性操作确认前没有副作用；拒绝后相关下游任务不执行。
- Agent 生成的画布结果可预览、接受或拒绝；接受后可撤销。
- Agent 使用用户自己的模型配置；密钥不会回传或写入日志。
- 用户可在账户中修改密码及注销；会话安全符合要求。忘记密码恢复不属于当前 MVP。

## 7. 前端设计交付

页面布局、Agent 任务状态和视觉规范见[产品与交互设计说明](../02-design/product-design.md)。现有原型需补 Agent 任务树/并行/审批/审阅状态；无需设计多人在线协作页。

## 8. 后续可重开议题

若之后要支持多人协作，需要另行设计项目分享/成员角色、实时协议、CRDT 文档迁移、权限撤销和运行期协作体验；本 MVP 不预留其行为承诺。

生图与改图接口将在后续接入：用户会提供两类接口及文档。当前只预留 Agent 工具适配边界，不开发 API 调用、鉴权或任务流程。接口细节清单见[图像生成与编辑 API 接入预案](../02-design/image-provider-integration.md)。
