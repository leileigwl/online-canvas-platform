# 产品与交互设计说明

> 版本：v1.1，2026-10-29。MVP 为单用户编辑；多人实时协作不在当前原型和 UI 范围内。

## 1. 设计目标

- 无限画布始终是主工作区，不呈现固定画板边界。
- 沿用黑色点阵视觉、简洁工具栏和高对比对象。
- 多 Agent 的规划、委派、审批、进度和结果一目了然，不把子任务塞成单一聊天流。
- 清晰展示自动保存、冲突、模型连接和任务错误状态。

## 2. 视觉与组件原则

- 主画布采用近黑背景、低对比点阵；点阵仅用于定位。
- 面板用深色层次、柔白文字、清楚的悬停/焦点/禁用状态。
- Agent 任务树区分 Coordinator 与专业 Agent，用状态图标加文字，不只依靠颜色。
- 费用/破坏性动作明确标出目标、影响和确认按钮。
- 首屏针对桌面宽屏；窄屏将素材、图层、Agent 面板折叠为抽屉，不承诺完整移动端编辑。
- 颜色、层级、页面网格与组件实现计划见[前端 UI 开发计划](frontend-ui-plan.md)；基础控件允许使用 shadcn/ui，但需匹配本产品令牌和原型，不沿用其默认外观。

## 3. 页面结构

### 3.1 登录与账户

- 用户名注册、登录页面；不收集邮箱，不做邮箱验证或邮箱找回。
- 注册时设置唯一用户名和密码；登录后可在账户设置中修改密码或注销。
- 忘记密码时 MVP 暂无自助恢复入口，页面应明确提示用户妥善保存凭证；恢复方案待后续决定。
- 字段错误贴近字段；服务错误显示于表单顶部。
- 账户菜单进入用户名/密码设置和登出。
- 已保存 API Key 只显示“已配置/更新密钥”，永不回显原文。

### 3.2 项目首页

- 顶部导航：产品标识、我的项目、账户菜单。
- 项目卡片显示名称、更新时间、画布缩略图和最近访问。
- 主操作为新建项目；空状态引导创建第一个项目。
- 项目创建只收集名称，成功后进入新项目并创建/打开画布。

### 3.3 无限画布编辑器

```text
┌ 返回 / 项目名 / 画布名 ─ 工具栏 / 会话草稿 / Agent ┐
│ 左侧素材/图层 │ 黑色点阵无限画布                │ Agent 执行区 │
│               │                              │ 任务/输出/审阅│
│               └────── 底部紧凑目标输入栏 ─────┘             │
└────────────────────────────────────────────────────────────┘
```

- 顶栏：返回项目、画布名、与“会话草稿”并排的选择/平移/撤销/重做工具栏、Agent 面板入口和账户入口。
- 左侧栏：画布入口、素材库入口和当前画布图层列表；图层行支持选择、显隐。
- 固定工具栏：固定在顶栏“会话草稿”状态旁，提供选择箭头、手形平移、图片导入、撤销和重做；文字、形状、连接线、画笔快捷图标继续从工具栏移除。左侧图层标题不显示添加按钮；缩放仍保留在画布左下角。
- 中间画布：无限二维坐标，无页面边缘；元素为图片、文字和基础形状。
- 右侧 Agent 面板只展示目标消息、执行进度、输出审阅和已选参考图片；不放输入框或“添加素材”弹层。点击画布图片会自动加入参考图列表；图片可在右侧或底部栏移除。Agent 可缩为窄栏。
- 画布底部放置紧凑目标输入栏，提示词、模型、参数摘要和提交按钮常驻；提交后在右侧显示 Agent 演示流程。点击参数摘要后，在画布范围内打开可滚动的图像设置浮层。设置包含质量、宽高尺寸、16 倍数对齐、分辨率、宽高比、透明背景和生成张数。当前只实现前端状态，不调用真实图像生成服务。
- 顶栏手形工具旁的“导入图片”将本地图片放到画布并加入底部参考图列表；画布上点击图片也会追加为参考并聚焦底部输入栏。底部不显示独立参考图选择弹层。
- 暂不显示分享、预览和顶栏缩放控件；保留画布左下角缩放操作。
- 对象选中后显示紧贴对象内容的变换框；选择工具在空白处拖拽可框选多个对象并批量复制、删除或变换。
- 右侧参考图片只从画布图片选择和顶栏导入中更新；选择素材不需要打开对话附件弹层。
- 原型保留既有画布对象和图层能力；常驻工具栏只显示选择、手形、图片导入、撤销/重做。
- 画布左下角显示缩放比例与缩放控件；底部目标输入栏负责提交 Agent 请求，并承载图像生成参数。

### 3.4 Agent 配置

- 模型配置字段：服务商显示名、OpenAI 兼容 HTTPS Base URL、API Key、模型名、连接测试。
- MVP Agent 角色：Coordinator、Planner、Canvas Editor、Reviewer。Image Creator 标记为“待接口接入”，当前不执行生图或改图。
- MVP 可用角色可启用/停用、选择已保存模型配置、设置超时/并发边界。
- 允许多个角色复用默认模型；密钥保存后不回显。
- 模型测试失败要区分地址、认证、模型不可用等错误，不记录密钥。

## 4. 无限画布交互

- 空格/中键拖动平移；滚轮/触控板缩放。
- 选择工具可单选、多选框选、移动和变换对象。
- 上传或从素材库拖入图片时，先显示放置预览。
- 画布图片对象只引用 asset ID；删除画布对象不删除素材库原图。
- 撤销/重做按照用户操作批次进行；Agent 应用的操作批次可整体撤销。
- 对象可复制、删除、改层级；键盘快捷键有可发现入口。

## 5. 多 Agent 团队体验

### 5.1 Agent 面板

- 顶部：Coordinator 状态、模型连接、取消运行。
- 右侧 Agent 展示区：已提交目标、参考图片选择、执行计划、输出和审阅；不提供独立输入框。
- 画布底部输入区：紧凑单行目标输入、模型选择、参数摘要和提交按钮；点击参数摘要弹出图像设置面板，提交后更新右侧 Agent 流程。
- 运行区采用“解析画布内容 → 生成视觉方案 → 检查并输出结果”三步主流程；在步骤说明里显示 Coordinator、Planner、Canvas Editor 和 Reviewer 的分工与独立任务状态。
- 每个阶段显示已完成、运行中或待开始；结果生成前不展示空提案卡，生成后在计划下方列出画布变更摘要并提供拒绝/应用，应用后可通过画布撤销恢复。
- 不显示 Agent 附件按钮或素材选择弹层。点击画布图片时自动加入已选参考图；顶栏导入图片后同步加入底部输入栏和右侧图片列表。
- Agent 面板支持收窄为窄栏并恢复，收窄后画布获得更多可用宽度。
- 历史区：最近对话、未完成任务和失败任务重试入口。

### 5.2 运行状态和操作

| 状态 | 界面表现 | 用户动作 |
|---|---|---|
| 准备上下文 | 正在整理画布和参考图片 | 取消 |
| 规划中 | Coordinator 拆解目标 | 取消 |
| 等待确认 | 显示计划、费用/风险和目标 | 确认、修改请求、拒绝 |
| 排队/执行中 | 子 Agent 和依赖分别显示状态 | 取消可取消任务 |
| 部分完成 | 成功产物与失败步骤分组 | 重试失败项、接受成功结果、结束运行 |
| 等待审阅 | 列出受影响对象和修改摘要 | 应用、放弃、查看差异 |
| 成功 | 汇总结果及已应用状态 | 继续对话、撤销批次 |
| 失败/取消 | 说明失败步骤和已产生副作用 | 重试、查看产物 |

- Coordinator 只展示任务摘要和行动计划，不展示内部思维链。
- 计划卡显示参与角色、先后依赖、可并行项、预计结果、可能费用/风险。
- 删除等破坏性操作确认前不执行；未来图像 API 收费确认方式等接口细节明确后再设计。
- 画布变更以新增/移动/修改/删除摘要预览，用户接受后一次应用为可撤销操作批次。
- Agent 执行期间用户仍可编辑；若画布状态有实质变化，提交前显示状态已更新并重验。
- 图像生成参数栏当前只保存本地界面状态；提交时明确提示尚未接入生成服务。真实 Image Creator 接口接入后，结果先进入素材库供预览，不自动插入画布。

用户只提交一次创作目标。Coordinator 安排不同职责的 Agent，用户查看的是计划、子任务进度和最终预览，不需要逐个启动或管理 Agent。拆分角色是为了区分“制定方案、提出画布操作、检查结果”，让权限和失败位置清楚；API 校验操作，用户确认后才写回。

### 5.3 用一个例子理解多 Agent

用户在画布里选中三张商品图，输入“把这三张图排成一张简洁的商品海报”。用户只需要提交一次目标，不需要自己挑 Agent 或在多个聊天窗口之间搬运结果：

1. Coordinator 判断需要先规划、再修改画布、最后检查，并把运行拆成有依赖的任务。
2. Planner 给出主图、标题、留白和次图位置等布局方案。
3. Canvas Editor 根据方案提出受限的新增/移动/缩放等画布操作；它不能运行任意代码，也不能绕过 API 直接改数据库。
4. Reviewer 检查重叠和层级，并给出结果摘要。
5. 用户在画布预览里接受或放弃整批改动；接受后才写入画布，且可整体撤销。

所以“多 Agent 自主协作”指系统根据任务自动选择并调度多个有边界的角色，展示各步骤状态，并形成可审阅的结果；不是让 Agent 不受限制地自行操作，也不是多人同时编辑。MVP 可以在确有独立工作的步骤并行，其余步骤按依赖顺序执行。此例不调用生图/改图 API。

### 5.4 后续 Image Creator

- Image Creator 需要分别调用用户后续提供的生图接口和改图接口；当前只有设计占位，不开发或模拟真实接口。
- 接口协议、模型/参数、异步进度、费用、鉴权和错误行为以用户提供的接口文档为准。
- 接入后由服务端工具适配层调用；结果先作为私有素材供用户审阅，用户选择后才插入画布。
- 完整待确认信息见[生图与改图 API 接入预案](image-provider-integration.md)。

## 6. 图片素材库

- 图片网格、搜索/筛选、上传、选择数量和使用方式清楚可见。
- 素材库是创作入口之一；卡片提供“添加到画布”快捷动作，多选后也可批量添加到画布或作为 Agent 参考素材。若从某张画布打开素材库，添加后返回该画布。
- 原型在当前应用运行期间按画布暂存编辑状态与撤销/重做历史，避免往返素材库重置画布；这不是线上保存能力，页面刷新后不会保留。
- 添加画布时提供排列预览；附加 Agent 时在输入区显示可移除缩略图。
- 空、上传中、格式错误、超限、网络失败和重试均有明确状态。

## 7. 保存、冲突和错误状态

- 自动保存状态区分未修改、保存中、已保存时间、保存失败和版本冲突。
- 网络失败时保留本地草稿并提供重试；不得显示为已保存。
- 多标签页/设备写入旧 revision 时显示冲突说明，提供保留草稿或载入服务器版本的恢复操作。
- 模型未配置、队列等待、Agent 超时、部分失败、取消中、结果待审阅分别展示。
- 未登录或无权访问的项目显示登录/返回项目入口，不显示空白画布误导用户。

## 8. 原型补画清单

现有图片仅作为视觉参考。UI 调试前建议补充：

1. 项目首页的空状态、项目卡片和新建项目流程。

3. Agent 配置中的角色模型映射和连接失败状态。

6. 窄屏右侧面板折叠状态。

## 9. 前端调试顺序

1. 页面路由、桌面布局、黑色点阵视觉和用户名/密码账户流程。
2. 单用户画布交互、素材多选和自动保存提示。
3. Agent 配置、Coordinator 计划、子任务树和费用审批。
4. 结果审阅、应用到画布、撤销和错误恢复。
5. 空、载入、保存失败、冲突和窄屏状态。

## 10. 名词

- **Coordinator：**接收用户目标、建立任务图、调度专业 Agent 并汇总结果的协调 Agent。
- **专业 Agent：**MVP 中由 Coordinator 委派 Planner、Canvas Editor 或 Reviewer；Image Creator 属于后续接入角色。
- **画布操作批次：**用户或 Agent 的一组可追溯、可整体撤销的画布变更。
