# 前端交互原型图目录（Phase 1 门控）

本目录存放 **FlowCanvas** 基于已确认视觉方向（**暖象牙美术馆浅色 `#F6F5F2` + 磨砂白胶囊浮层 + 深碳黑主按钮 + 精密克莱因蓝选框 + 左侧极细竖排工具栏**）制作的高保真可交互 HTML 原型图。  
**工作规则（强制门控）**：任何针对 `apps/web/` 的页面样式与交互布局重构，必须先在本目录完成原型图更新并经用户确认，**确认通过后再编写或修改 `apps/web/` 页面代码**。

## 当前原型文件

- [`flowcanvas-prototype.html`](flowcanvas-prototype.html)：支持顶部视图切换（**画布工作台 / 首页画布库 / 素材库 / 模型与生图设置 / 登录注册**），使用统一摄影级示例素材（`apps/web/public/assets/sample-*.jpg`），覆盖全站核心交互状态：
  1. **无限画布工作台（暖象牙浅色工作室）**：
     - 全屏暖象牙微点阵无限空间，拖动零回弹（GPU `translate3d` 合成，实际前端配合 Konva `dragLayer` + IndexedDB 异步防抖缓存）；支持 `选择 (V)` 框选多选与 `抓手 (H/Space)` 全局平移，以鼠标为中心滚轮缩放及点击百分比自适应视图。
     - 顶部居中单一磨砂白胶囊直接提供「画布库 / 素材库 / 设置」1 键跳转、**可点击行内重命名**的画布标题、同步版本号、缩放、`版本`（精简关键快照不滥增）、**`导出`（整张画布 PNG / 选中单图）** 与 `AI Agent` 开关；右上角常驻紧凑账户/登录胶囊。
     - 左侧边缘极细竖排线性 SVG 工具胶囊（无 Emoji，**仅悬停显示带 PS 快捷键的自定义提示**）：抽屉开关、选择 (`V`)、抓手 (`H`)、撤销 (`Ctrl+Z`)、重做 (`Ctrl+Shift+Z`)、**文字工具 (`T` · 双击编辑/字号/字体/颜色)**、**自由画笔 (`B` · 笔色/粗细)**、**局部对齐（仅选中 ≥2 项时生效，绝不乱动未选中图）**、真实本地文件上传、**删除 (`Del/Backspace`)**。
     - **右下角可折叠全局小地图（Minimap）**：实时绘制画布元素缩略与当前视口蓝框，支持点击/拖拽平移视野；右侧 AI Agent 抽屉自动上让 `bottom` 避免重叠。
     - 右侧可折叠 AI Agent 抽屉（SSE 实时流式展示可折叠 `Thinking` 思考过程、结构化工具调用卡片、提案预览与整批撤销）。
     - 底部居中悬浮创作胶囊（「直接生图 / 改图」与「AI Agent」分段切换；点击画布图片纯边框静默引用为 `图1/图2/图3` 并带一键**「清空参考」**按钮，按 `0/1/2+` 张数动态切换生图参数）。
  2. **首页 / 画布库**：顶部居中导航、支持上传 0/1/2 张参考图并按图数动态适配配比参数、支持**自定义命名新建空白画布**进入完全空白画布，未登录引导登录。
  3. **我的素材库**：记忆来源画布 ID，上传或点击「上画布」直接插入并跳回来源画布，未登录态明确引导登录。
  4. **模型与生图设置**：语言模型（AI Agent）与 AI 生图/改图服务（OpenAI 兼容 / 百炼 / 硅基流动）双 BYOK 配置区与连通测试状态。
  5. **登录 / 注册**：独立居中暖象牙卡片（无顶部冗余胶囊导航，仅留左上角返回首页入口），不采集邮箱。
