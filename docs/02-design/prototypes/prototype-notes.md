# MVP 原型说明

> 首版按单用户编辑设计，不包含多人同时编辑、项目成员、在线光标和实时同步。

## 视觉方向

近黑色无限工作区、低对比灰色点阵、柔白文字和简洁工具。点阵只是空间线索，不形成固定画板边缘。沿用用户喜欢的黑点点风格，不加入提示词库、音乐或视频。

## 页面和动作

| 页面 | 关键内容 | 主要动作 |
|---|---|---|
| 登录/注册 | 唯一用户名和密码 | 注册、登录、登出；不收集邮箱 |
| 项目首页 | 我的项目、最近访问、新建 | 创建、打开、重命名、删除 |
| 无限画布 | 顶栏工具栏/点阵/素材和图层/右侧 Agent 对话/底部紧凑图像生成栏 | 选择/平移、框选、对象编辑、显隐、撤销/重做、缩放、对象上下文、图像参数和参考图片 |
| 图片素材库 | 私有素材、搜索和多选、卡片快捷操作 | 单张直接添加回来源画布，或多选批量添加到画布/Agent |
| Agent 团队设置 | 自有模型接口与 API 密钥设置 | 配置服务商、地址、密钥和模型；角色映射后端实现时再完善 |
| Agent 运行面板 | Coordinator 解析、Planner/Canvas Editor 方案、Reviewer 检查三步任务 | 参考素材增删、确认/拒绝提案、应用/撤销 |
| 账户设置 | 用户名和账户安全 | 改密码、注销；不重复展示账户方式说明；忘记密码恢复暂不支持 |

## Agent 为什么在画布里

右侧 Agent 面板是唯一 Agent 对话窗口，包含消息输入、执行计划、任务、输出和结果审阅；面板可收窄后恢复。Agent 可从素材库选择或临时导入参考图。图层在画布左侧维护。画布底部只保留紧凑图像生成栏，包含提示词、模型、参数摘要和生成按钮。

点击底部图像参数摘要，在画布区域内打开可滚动的设置浮层，提供质量、宽高尺寸、16 倍数对齐、分辨率、宽高比、透明背景和生成张数（1–10）。设置和提交目前只做本地交互，不调用真实图像生成服务。导入的参考图先作为临时内容，不会自动进入资产库。

选中画布中的图片或文本框后，可用对象工具条把对象加入右侧 Agent 对话上下文。图片作为参考附件，文本框标题和内容作为上下文；不打开对象专属 AI 输入浮层。

常驻工具栏仅显示选择箭头、手形平移、撤销和重做，并与“会话草稿”状态同处顶栏；文字、图片、形状、连接线与画笔图标从该工具栏移除。左侧图层区的添加按钮进入文本框放置模式。缩放仍独立位于画布左下角。

Agent 是把用户说的创作目标转成画布可执行操作的助手。例如用户选中商品图并提出海报目标，Planner 形成版式，Canvas Editor 提出移动/缩放等操作，Reviewer 检查后展示预览。用户接受后才应用，可撤销。

这样设计是为了减少用户逐个摆放素材的重复操作，同时让每一步有明确职责和边界：Coordinator 负责任务分配，专业 Agent 各做计划、画布编辑或检查，API 负责权限和 revision 校验。Agent 不能直接写数据库或执行任意代码；MVP 也不调用尚未提供的生图/改图 API。

## 多 Agent 状态

- 规划：Coordinator 摘要目标、Agent 角色和任务依赖。
- 并行执行：专业 Agent 分别显示状态和结果摘要。
- 等待审批：显示目标、可能费用/副作用及确认/拒绝按钮。
- 部分失败：成功产物与失败任务分组，重试不重复已完成副作用。
- 待审阅：列出画布对象差异；用户接受后写入个人画布。
- 凭证隐私：显示模型已配置，不显示 API Key。

## 保存和错误状态

- 保存中、已保存、保存失败、版本冲突均有明确状态。
- 保存失败时保留可恢复草稿；旧 revision 写入时提供保留草稿或载入服务端版本。
- Agent 模型未配置、任务排队/超时、取消中和部分失败都提供下一步操作；生图/改图失败状态待接口接入后设计。
- 导入图片与模拟生成结果在“保存到资产”前只作为临时内容；点击保存后才进入资产库。当前前端用对象 URL 和内存状态模拟，刷新后会消失。
- 素材上传中、格式错误、超限和访问失败有对应提示。

## 画布基础操作

- 选择工具在空白区域拖拽框选对象；选中后可批量移动/变换、复制和删除。
- 画笔支持自由绘制及基础颜色选择；图层列表中的眼睛图标切换对象显隐。
- 图片标签与图片画面分层绘制，选中框只包围图片内容；画布左下角缩放控件可恢复 100%。
- 对象工具条可以给便签、形状、连接线和画笔改色；常驻选择/平移/撤销/重做工具栏固定在顶栏“会话草稿”旁，不随画布或页面高度变化。
- 素材库是独立的创作入口：卡片可单张直接添加到来源画布，多选后可批量添加到画布，也可附加给 Agent。
- 从画布进入素材库再添加图片时，原型按画布 ID 在当前应用运行期间暂存画布对象和撤销/重做历史，返回后保留原编辑并插入图片。该内存草稿不等于云端自动保存，刷新/关闭浏览器后的恢复尚未实现。
- Agent 面板将对话输入与三步任务进度放在同一侧栏，审阅动作置于任务结果下方；画布底部的图像生成栏与 Agent 对话分开。
- Agent 面板初始状态呈现阶段进度；提案仅在用户提交目标后展示。Agent 配置页维持清晰的大尺寸内容字段，同时把左侧导航栏收窄至约 168–190px。
- 对象选中框使用 1px 蓝色实线和 7px 浅色控制点，图片边框仅包围图片内容，不把下方标题标签框入。
- 上述画布动作目前只存在于前端演示状态，不代表云端保存或服务端素材上传已经实现。

## 原型走查顺序

先走查用户名注册/登录和项目首页；再走查单人画布、素材多选和保存冲突；最后走查 Agent 配置、计划、并行任务、审批和结果审阅。补齐空、载入、错误和窄屏状态。
