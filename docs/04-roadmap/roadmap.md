# 产品与工程路线图

## 阶段 0：需求分析

- **状态：完成。**MVP 为个人在线无限画布与多 Agent 创作；多人同时编辑暂不考虑。

## 阶段 1：产品设计和技术基线

- **状态：完成。**PRD、页面交互、数据模型、系统架构、技术选型和 OpenSpec 已更新。
- 下一步由用户按原型清单补 Agent 状态和保存/冲突原型。

## 阶段 2：UI 前端调试

- 建立登录、账户、项目、画布、素材和 Agent 设置界面。
- 用模拟数据走通单用户画布、素材操作、多 Agent 任务树、审批/结果预览。
- 核对空/载入/错误/revision 冲突与窄屏状态。

## 阶段 3：平台服务与 MVP 联调

- 建 Monorepo/Compose、账户/个人项目 API、PostgreSQL 和 MinIO。
- 实现 JSONB 画布快照、revision 保存/恢复和图片素材流程。
- 实现 LangGraph 多 Agent、ARQ Worker、BYOK 模型配置、审批和运行恢复。
- 完成真实 API、数据库、对象存储和 Agent 供应商端到端流程。

## 阶段 4：部署与后续评估

- 单台服务器部署 HTTPS、资源限制、监控和异机备份。
- 完成故障恢复与权限/费用验收。
- 多人实时协作、团队空间、计费、移动端和媒体扩展待需求明确后另行规划。
- 生图/改图接口由用户后续提供；收到接口文档后按[接入预案](../02-design/image-provider-integration.md)单独规划实现。

当前最近一步是补完 Agent 原型，然后开始 UI 前端调试；尚未开始应用代码实现。
