# Spec Delta

## Purpose

定义单个用户如何在无限画布中创建和修改对象，并将文档自动保存、版本保护和恢复到服务端，支持用户在不同会话继续创作。

## ADDED Requirements

### Requirement: 无限画布空间
系统 MUST 提供没有预设页面边界的二维工作区，用户可任意平移视口、缩放并摆放多个画布对象。

#### Scenario: 在无限空间中移动视口
- **WHEN** 用户拖动画布或使用触控板平移
- **THEN** 视口按方向移动且不会遇到隐式画布边界

#### Scenario: 在不同位置添加对象
- **WHEN** 用户在任意空白位置添加或移动对象
- **THEN** 系统按画布坐标保存对象位置并保持空间关系

#### Scenario: 缩放与恢复视口
- **WHEN** 用户调整缩放比例并保存画布
- **THEN** 系统保存视口中心和缩放，重新打开时恢复用户上次视图

### Requirement: 画布对象编辑
系统 MUST 允许用户添加、选择、变换和删除图片、文字及基础形状，并将对象样式和资源引用纳入画布文档。

系统 MUST 支持基础自由画笔、图层显隐和空白区域框选多对象。

#### Scenario: 添加与修改对象
- **WHEN** 用户添加或改变画布对象
- **THEN** 系统保存对象类型、坐标、尺寸、样式和资源引用

#### Scenario: 删除画布图片对象
- **WHEN** 用户删除引用图片素材的画布对象
- **THEN** 系统删除画布引用但保留素材库原文件，除非用户另行删除素材

#### Scenario: 框选多个对象并编辑
- **WHEN** 用户使用选择工具在画布空白区域拖出框选矩形
- **THEN** 系统选中相交的可见对象，并允许批量变换、复制或删除

#### Scenario: 绘制和显隐
- **WHEN** 用户使用画笔绘制或切换某图层的可见状态
- **THEN** 系统将笔迹作为可编辑画布对象保存，并按图层状态显示或隐藏对象

### Requirement: 画布工具与参考图片
系统 MUST 在编辑器顶栏“会话草稿”状态旁提供固定工具栏，显示选择箭头、手形平移、图片导入、撤销和重做；缩放操作继续固定在画布左下角。左侧图层区只显示图层名称、搜索和图层列表，不显示标题旁的添加按钮。选中框 MUST 使用细边框和较小的控制点，工具栏 MUST 在视口变化时保持可见。素材库单张“添加到画布”操作 MUST 返回来源画布并加入素材。用户从顶栏导入的图片 MUST 作为图片对象放到画布并加入底部参考列表；点击画布图片 MUST 追加该图为参考。

画布底部 MUST 提供唯一的目标输入栏，用户从该处提交创作目标并在右侧查看 Agent 执行过程。右侧 Agent 面板 MUST 只展示已提交目标、执行、输出审阅和已选参考图片，不得出现第二个输入框或素材添加弹层。用户点击画布图片时 MUST 自动将图片追加到右侧和底部的参考列表。

用户选中画布图片时，系统 MUST 将该图片追加到画布底部参考图列表并聚焦目标输入。底部输入栏 MUST 不提供单独的参考图片选择弹层。

#### Scenario: 绘制时工具栏保持可见
- **WHEN** 用户在画布上绘制或浏览器可视高度变化
- **THEN** 顶栏工具栏保持可见且可操作，不受画布视口尺寸影响

#### Scenario: 点击图片加入创作参考
- **WHEN** 用户在画布上点击图片
- **THEN** 图片自动加入右侧已选图片和底部参考列表
- **AND** 底部目标输入获得焦点

#### Scenario: 将多张导入图片加入参考
- **WHEN** 用户通过顶栏导入多张图片
- **THEN** 图片对象放入画布且缩略图追加至底部和右侧参考列表

#### Scenario: 从顶栏导入图片
- **WHEN** 用户点击手形工具旁的“导入图片”并选择一张或多张图片
- **THEN** 系统将图片放到画布并作为当前图像生成参考
- **AND** 底部输入栏不打开参考图片选择弹层

#### Scenario: 设置对象颜色
- **WHEN** 用户选中可配色对象并从对象工具条选择颜色
- **THEN** 系统将颜色应用于所有选中对象并纳入撤销历史

#### Scenario: 从素材卡片直接添加
- **WHEN** 用户在素材库卡片上点击“添加到画布”
- **THEN** 系统将素材插入进入素材库前的画布并返回该画布
- **AND** 保留离开画布前的对象状态和可撤销操作历史

### Requirement: 底部目标输入与图像参数
画布 MUST 在底部提供紧凑目标输入栏和图像参数入口；用户点击参数摘要时 MUST 在画布区域内打开可滚动的图像设置浮层，包含质量、宽高尺寸、16 倍数对齐、分辨率、宽高比、透明背景和 1–10 张生成数量。参数变化 MUST 同步至摘要。提交目标后，右侧 Agent 面板 MUST 展示本地演示流程；原型 MUST 明确提示未接入真实图像生成服务，且 MUST NOT 调用外部生成 API。

#### Scenario: 调整图像参数
- **WHEN** 用户点击底部输入栏的参数摘要并选择质量、尺寸、分辨率、宽高比、透明背景或张数
- **THEN** 系统在画布范围内显示参数设置浮层并更新紧凑栏的摘要
- **AND** 提交目标时右侧展示本地 Agent 流程，并提示当前未连接真实图像生成服务

#### Scenario: 调节视图缩放
- **WHEN** 用户使用画布缩放控件选择缩放步进或恢复 100%
- **THEN** 系统按所选比例缩放画布视口，并同步更新缩放百分比

### Requirement: 画布文档持久化与恢复
系统 MUST 保存画布文档、版本号和 schema version，并允许所有者浏览历史快照及恢复所选版本。恢复历史快照 MUST 创建更高的新 revision，并保留恢复前的当前文档。

#### Scenario: 重新打开画布
- **WHEN** 用户重新打开其已保存画布
- **THEN** 系统返回可恢复的文档内容、revision 和视口

#### Scenario: 浏览并恢复历史快照
- **WHEN** 所有者在无未保存更改时查看画布版本并恢复一个历史 revision
- **THEN** 系统返回当前版本和最近历史快照
- **AND** 恢复后的文档与视口取自所选快照，revision 单调递增
- **AND** 恢复前的当前文档仍可从版本记录中恢复

### Requirement: 自动保存与失败恢复
系统 MUST 在画布变更后自动提交保存，并在网络或服务错误时保留未保存内容和重试入口。

#### Scenario: 自动保存成功
- **WHEN** 用户编辑且保存请求成功
- **THEN** 系统持久化最新文档并显示新的 revision 与更新时间

#### Scenario: 自动保存失败
- **WHEN** 保存请求失败
- **THEN** 系统保留浏览器当前文档并显示可重试的未保存状态

#### Scenario: 网络恢复后自动重试
- **WHEN** 画布保存因网络或服务端临时错误失败，之后浏览器恢复联网
- **THEN** 系统从浏览器持久草稿自动重试保存并在成功后清除待同步状态
- **AND** 对于版本冲突，系统仍要求用户选择本地草稿或云端版本

### Requirement: 旧版本写入保护
系统 MUST 检查保存请求的 base revision，防止旧标签页或设备静默覆盖更新版本。

#### Scenario: revision 已过期
- **WHEN** 保存请求的 base revision 小于服务端当前 revision
- **THEN** 系统拒绝覆盖并返回当前版本信息及冲突恢复选项

### Requirement: 用户操作撤销与恢复
系统 MUST 允许用户撤销和恢复有记录的画布操作批次。

#### Scenario: 撤销本人操作
- **WHEN** 用户撤销最近的可逆操作批次
- **THEN** 系统恢复该批次之前的个人画布状态并自动保存

#### Scenario: 恢复已撤销操作
- **WHEN** 用户恢复先前撤销的操作
- **THEN** 系统重新应用对应变更并自动保存

#### Scenario: 整体撤销 Agent 提案
- **WHEN** 用户应用 Agent 提案后撤销该批次
- **THEN** 系统将提案中的所有操作作为一个撤销步骤恢复并自动保存
- **AND** Agent Reviewer 状态同步显示已撤销，重做时整批恢复并同步显示已应用
- **AND** 应用期间若画布有新的本地编辑，系统进入 revision 冲突处理，不覆盖该编辑
