# MVP 原型说明

> 首版按单用户编辑设计，不包含多人同时编辑、项目成员、在线光标和实时同步。

## 视觉方向

近黑色无限工作区、低对比灰色点阵、柔白文字和简洁工具。点阵只是空间线索，不形成固定画板边缘。沿用用户喜欢的黑点点风格，不加入提示词库、音乐或视频。

## 页面和动作

| 页面 | 关键内容 | 主要动作 |
|---|---|---|
| 登录/注册 | 唯一用户名和密码 | 注册、登录、登出；不收集邮箱 |
| 项目首页 | 我的项目、最近访问、新建 | 创建、打开、重命名、删除 |
| 无限画布 | 顶栏工具栏/点阵/素材和图层/右侧 Agent 流程区/底部目标输入栏 | 选择/平移、图片导入、框选、对象编辑、显隐、撤销/重做、缩放、图像参数和参考图片 |
| 图片素材库 | 私有素材、搜索和多选、卡片快捷操作 | 单张直接添加回来源画布，或多选批量添加到画布/Agent |
| Agent 团队设置 | 自有模型接口、API 密钥与四角色模型映射 | 配置服务商、地址、密钥和模型；密钥加密保存，连接测试由 API 处理 |
| Agent 运行面板 | Coordinator 解析、Planner/Canvas Editor 方案、Reviewer 检查三步任务 | 参考素材增删、确认/拒绝提案、应用/撤销 |
| 账户设置 | 用户名和账户安全 | 改密码、注销；不重复展示账户方式说明；忘记密码恢复暂不支持 |

## Agent 为什么在画布里

右侧 Agent 面板只展示已提交目标、执行计划、任务、输出审阅和已选参考图；面板可收窄后恢复，不提供输入框或“添加素材”弹层。图层在画布左侧维护。画布底部是唯一目标输入栏，包含提示词、执行方式摘要、已选参考图缩略图和提交按钮。点击画布图片会自动追加为参考；顶栏手形工具旁的“导入图片”会将本地图片放到画布并加入底部参考列表。

点击底部任务参数摘要，在画布区域内打开可滚动的设置浮层。用户可在同一输入栏选择“画布协作”或“图片生成”：画布协作提交给 Coordinator 多 Agent；图片生成时提供质量、宽高尺寸、16 倍数对齐、分辨率、宽高比、透明背景和生成张数（1–10），参数与参考图 ID 随 AgentRun 传给独立 Image Creator Worker。示例 fixture 画布只用于展示画布协作，图片生成需要已保存到云端的 UUID 画布。默认 Provider 未配置且不联网，未配置时显示明确错误。顶栏导入图片会上传到私有素材并加入画布与参考列表。

点击画布图片会自动将其加入右侧已选图片和底部参考列表；用户可从任一位置移除。创作目标在底部输入并提交，右侧仅展示执行过程和结果，不创建对象专属 AI 输入浮层。

常驻工具栏显示选择箭头、手形平移、图片导入、撤销和重做，并与“会话草稿”状态同处顶栏；文字、形状、连接线与画笔图标从该工具栏移除。左侧图层标题不显示添加按钮。缩放仍独立位于画布左下角。

Agent 是把用户说的创作目标转成画布可执行操作的助手。例如用户选中商品图并提出海报目标，Planner 形成版式，Canvas Editor 提出移动/缩放等操作，Reviewer 检查后展示预览。用户接受后才应用，可撤销。

这样设计是为了减少用户逐个摆放素材的重复操作，同时让每一步有明确职责和边界：Coordinator 负责任务分配，专业 Agent 各做计划、画布编辑或检查，API 负责权限和 revision 校验。Agent 不能直接写数据库或执行任意代码；MVP 也不调用尚未提供的生图/改图 API。

## 多 Agent 状态

- 规划：Coordinator 摘要目标、Agent 角色和任务依赖。
- 并行执行：专业 Agent 分别显示状态和结果摘要。
- 等待审批：显示目标、可能费用/副作用及确认/拒绝按钮。
- 部分失败：成功产物与失败任务分组，重试不重复已完成副作用。
- 待审阅：列出画布对象差异；用户接受后写入个人画布。
- 凭证隐私：显示模型已配置，不显示 API Key。

## 保存和错误状态

- UUID 画布显示保存中、已保存、保存失败、版本冲突等状态；示例画布仍为本地 fixture。
- 保存失败时在浏览器本地保留可恢复草稿；旧 revision 写入时提供保留本地草稿或载入服务端版本。重新联网后自动重试。
- Agent 模型未配置、任务排队/超时、取消中和部分失败都提供下一步操作；生图/改图失败状态待接口接入后设计。
- 未上传的附件使用临时状态；正式素材通过 API 上传并进入私有存储。生图结果只有在 Provider 配置成功后才会作为临时私有素材返回。
- 素材上传中、格式错误、超限和访问失败有对应提示。

## 画布基础操作

- 选择工具在空白区域拖拽框选对象；选中后可批量移动/变换、复制和删除。
- 画笔支持自由绘制及基础颜色选择；图层列表中的眼睛图标切换对象显隐。
- 图片标签与图片画面分层绘制，选中框只包围图片内容；画布左下角缩放控件可恢复 100%。
- 对象工具条可以给便签、形状、连接线和画笔改色；常驻选择/平移/撤销/重做工具栏固定在顶栏“会话草稿”旁，不随画布或页面高度变化。
- 素材库是独立的创作入口：卡片可单张直接添加到来源画布，多选后可批量添加到画布，也可附加给 Agent。
- 从画布进入素材库再添加图片时，编辑器按画布 ID 保留状态；UUID 画布的本地草稿会跨刷新恢复，并继续同步到云端。
- Agent 目标输入放在画布底部；右侧面板仅展示任务进度、结果审阅和已选参考图片。
- 清空 Agent 对话时同时清除本轮消息、执行计划、提案结果和已选参考图片；已应用到画布的操作仍留在画布上。
- Agent 面板初始状态呈现阶段进度；提案仅在用户提交目标后展示。Agent 配置页维持清晰的大尺寸内容字段，同时把左侧导航栏收窄至约 168–190px。
- 对象选中框使用 1px 蓝色实线和 7px 浅色控制点，图片边框仅包围图片内容，不把下方标题标签框入。
- 示例画布仍使用前端 fixture；登录后的 UUID 画布、正式资产和 Agent 提案已接入 API。图片生成仍依赖尚未配置的抽象 Provider；未上传附件是本地临时状态。

## 原型走查顺序

走查用户名注册/登录、项目空状态和 CRUD；再走查 UUID 画布、素材多选、断网重试和 revision 冲突；最后走查 Agent 角色配置、排队/并行/取消/失败、提案审阅和整批撤销/重做。桌面流程已接通，空状态、部分任务失败和窄屏抽屉仍待全量复核。
