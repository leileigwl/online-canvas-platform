# PRODUCT.md：产品边界

> 状态：上线重构版产品基线已锁定（2026-11-11）。产品定位为「**可开源自托管的在线 AI 无限画布与视觉创作工作台**」，覆盖公网 Web 端与面试演示场景。详细需求见 [`docs/01-product/PRD.md`](01-product/PRD.md)。

## 产品是什么

**FlowCanvas** 是一款面向个人视觉创作者、设计师与开发者的在线 AI 无限画布工作台。用户在全屏暖象牙浅色美术馆质感无限画布中组织图片素材、便签与形状，既能通过底部悬浮创作栏直接调用 AI 文生图/参考图改图并将结果自动落入画布，也能下达复杂排版目标由多 Agent 协同规划并生成安全可控的画布修改提案。

## 目标用户

- 需要在无限空间中收集参考图、通过 AI 连续生成/迭代视觉素材并整理版面的个人创作者。
- 希望私有部署、自行掌控模型与生图 API Key（BYOK）的开源开发者与小团队。
- 面试演示场景下的访客（通过作者预置的演示账号与示例画布直接体验完整闭环）。

## 上线版（当前规划范围）做什么

- **账户与登录引导（未登录隔离）**：
  - 唯一用户名 + 密码注册、登录、登出、改密与注销（不收集邮箱）；
  - 未登录访问「我的画布空间」与「素材库」时明确引导登录；在首页输入的提示词、参考图与生图配比参数会暂存至登录完成后自动创建画布并续接执行；点击「新建空白画布」直接进入完全空白画布；
  - 新注册用户自动初始化 1 张引导示例画布，并提供 CLI 脚本一键初始化面试演示账号（含精选作品与模型/生图 Key）。
- **全屏无限画布编辑器（暖象牙美术馆浅色工作台）**：
  - 全屏 `#F6F5F2` 暖象牙微点阵无限画布，磨砂白浮层 + 深碳黑主按钮 + 精密克莱因蓝选框 + 极细线性矢量图标（零 Emoji，悬停显示 PS 快捷键提示）；
  - 工具与视图：支持 `选择 (V)` 框选多选、`抓手 (H/Space)` 全局平移、以指针为中心的滚轮缩放与自适应视图、**文字工具 (`T` · 双击编辑/字体/颜色)**、**自由画笔 (`B` · 笔色/粗细)**、**删除 (`Del/Backspace`)**、选中多对象局部网格对齐、本地选图上传、一键**导出整张画布/选中图片 PNG**、顶部标题直接重命名、底栏一键清空参考图，以及**右下角可折叠全局小地图（Minimap）**支持点击/拖拽视口导航；
  - 左右两侧抽屉均支持独立开关，从画布进入「完整素材库」自动记忆来源画布并原路插入返回；
  - 浏览器端异步 **IndexedDB**（500ms 防抖）保存未同步草稿、`revision` 乐观锁冲突保护与精简版云端历史快照一键恢复。
- **直接生图 / 参考图改图（BYOK + 自动上画布）**：
  - 首页与画布底栏均支持上传/点选参考图，并支持画面比例（`3:4`、`1:1`、`16:9`、`4:3` 等）、分辨率、质量、16 倍数对齐、透明背景与张数等生图配比；
  - 底栏切换为「直接生图 / 改图」时直接调用用户配置的生图服务，在当前视口创建动态占位节点，经 ARQ Worker 完成后自动转存 MinIO 私有存储并落入画布，不打开 Agent 面板。
- **LangGraph 创意与画布统一 Agent（流式思考 + 结构化工具卡）**：
  - 底栏切换为「AI Agent」时打开右侧悬浮面板，通过真实 SSE 流式展示可折叠「思考过程（Thinking）」与结构化「工具调用卡」（图标 + 动作摘要 + 状态，JSON 参数默认折叠）；
  - 服务端统一白名单工具覆盖创意生图/改图（`generate_image`、`edit_image`）与画布操作（`add_note`、`move_object`、`resize_object`、`align_objects`、`add_shape`），无需 RAG 文档切分；画布修改类提案经用户预览并点击确认后才写入数据库，支持整批一键撤销。
- **个人素材库与 BYOK 模型设置**：
  - 私有图片上传（12 MiB / 100 MP 限制）、收藏、搜索、多选批量上画布或附加为参考；
  - 设置页分模块配置「语言模型（支持 4 个 Agent 角色独立指定模型 ID）」与「AI 生图/改图服务（OpenAI 兼容 / 百炼 / 硅基流动）」，密钥服务端加密存储且永不回显。
- **单机全栈自托管**：
  - Docker Compose 一键编排 Web/Caddy、FastAPI、ARQ Worker、PostgreSQL 18、Redis 7、MinIO，支持自动 HTTPS 或挂在 1Panel Nginx 反代后运行，配套备份与恢复脚本。

## 上线版明确不做什么

- 不做多人实时协同编辑（不引入 Yjs / Hocuspocus、WebSocket 光标或成员邀请/团队空间）。
- 不由平台无限制免费代付外部 AI 生图与对话费用（公网访客默认自行填写 BYOK Key，仅由管理员手动维护演示账号）。
- 不做视频生成、音频生成、3D 导演台、公开提示词社区、支付订阅或后台运营管理系统。
- 不允许 Agent 执行任意代码、Shell、SQL 或未在白名单登记的画布破坏性操作。

## 支持的核心用户操作

1. **首页直达或进入画布**：登录后在首页输入创作目标直接新建画布并开启生成，或打开最近画布与预置示例画布。
2. **配置 BYOK 模型与生图服务**：在设置页填入语言模型和生图服务的 HTTPS 接口、模型名与 API Key 并测试连通性。
3. **画布生图与参考迭代**：在画布底部选择「AI 生图」输入提示词（可选点选画布图片作参考）→ 画布出现生成占位节点 → 完成后自动加载入画布并沉淀至私有素材库。
4. **多 Agent 智能排版**：切换「智能排版」输入“把选中的商品图按网格对齐并补充标题便签” → 右侧 Agent 抽屉经 SSE 实时展示 4 角色进度 → 审阅提案后应用或整批撤销。
5. **版本与素材管理**：在左侧可折叠抽屉检索图层与个人素材，通过历史版本弹窗恢复任意历史 revision。
