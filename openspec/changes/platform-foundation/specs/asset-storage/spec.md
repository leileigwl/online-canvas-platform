# Spec Delta

## Purpose

定义个人图片素材的上传、所有权、画布引用和 Agent 参考规则，使图片文件与业务/画布文档分开保存并始终受用户所有权保护。

## ADDED Requirements

### Requirement: 私有图片上传
系统 MUST 校验图片上传并保存到平台控制的私有文件存储，同时记录所有者和可恢复元数据。

#### Scenario: 上传有效图片
- **WHEN** 用户上传符合格式和大小限制的图片
- **THEN** 系统保存文件并返回归属当前用户的素材标识与元数据

#### Scenario: 上传无效图片
- **WHEN** 上传内容不是允许的图片或超过限制
- **THEN** 系统拒绝上传并返回可理解的错误

### Requirement: 个人画布素材引用
系统 MUST 允许用户将自己拥有的图片引用到画布，且画布文档只保存资源标识及布局信息。

#### Scenario: 插入自有素材
- **WHEN** 用户将个人图片素材插入自己的画布
- **THEN** 系统创建画布对象引用而不把图片二进制写入画布文档

#### Scenario: 多选图片添加到画布
- **WHEN** 用户多选自有图片并确认添加
- **THEN** 系统为每张图片创建独立画布对象并保存文档

### Requirement: Agent 参考图片授权
系统 MUST 只向用户发起的 Agent 任务提供该用户拥有且明确附加到当前任务的图片。

#### Scenario: 用户附加参考素材
- **WHEN** 用户将一张或多张自有图片附加给 Agent
- **THEN** 当前任务只能读取这些受控引用，且用户发送前可移除附件

#### Scenario: Agent 请求其他图片
- **WHEN** Agent 尝试读取未附加或不属于当前用户的素材
- **THEN** 系统拒绝访问并记录未授权调用

### Requirement: 私有素材访问
系统 MUST 在读取图片或发放临时访问凭证前校验素材所有权。

#### Scenario: 用户读取自己的素材
- **WHEN** 用户请求其个人图片
- **THEN** 系统返回有效的受限图片访问方式

#### Scenario: 用户读取他人私有素材
- **WHEN** 用户请求不属于自己的图片
- **THEN** 系统拒绝请求且不泄露素材是否存在
