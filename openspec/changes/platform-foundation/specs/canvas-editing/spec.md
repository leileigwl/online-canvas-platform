# Spec Delta

## Purpose

定义单个用户如何在无限画布中创建和修改对象，并将文档自动保存、版本保护和恢复到服务端，支持用户在不同会话继续创作。

## ADDED Requirements

### Requirement: 无限画布空间
系统 MUST 提供没有预设页面边界的二维工作区，用户可任意平移视口、缩放并摆放多个画布对象。

#### Scenario: 在无限空间中移动视口
- **WHEN** 用户拖动画布或使用触控板平移
- **THEN** 视口按方向移动且不会遇到隐式画布边界

#### Scenario: 在不同位置添加对象
- **WHEN** 用户在任意空白位置添加或移动对象
- **THEN** 系统按画布坐标保存对象位置并保持空间关系

#### Scenario: 缩放与恢复视口
- **WHEN** 用户调整缩放比例并保存画布
- **THEN** 系统保存视口中心和缩放，重新打开时恢复用户上次视图

### Requirement: 画布对象编辑
系统 MUST 允许用户添加、选择、变换和删除图片、文字及基础形状，图片内容通过素材引用关联。

系统 MUST 支持基础自由画笔、图层显隐和空白区域框选多对象。Agent 面板 MUST 只展示 Agent 执行、输出和审阅；用户从编辑器底部对话区选择参考素材，素材库和图层管理不得作为 Agent 面板重复标签出现。

系统 MUST 提供锚定在可视画布顶部的固定工具栏，只显示选择箭头、手形平移、撤销和重做；图片、文字、形状、连接线和画笔快捷图标 MUST 从该工具栏移除。缩放操作继续固定在画布左下角。选中单张图片时 MUST 提供该图专属的 AI 对话输入，并将该图片附加到提交给 Agent 的请求。画布工具栏 MUST 在绘制及视口尺寸变化时保持可见。素材库单张“添加到画布”操作 MUST 返回进入素材库前的画布并加入该素材。

#### Scenario: 添加与修改对象
- **WHEN** 用户添加或改变画布对象
- **THEN** 系统保存对象类型、坐标、尺寸、样式和资源引用

#### Scenario: 删除画布图片对象
- **WHEN** 用户删除引用图片素材的画布对象
- **THEN** 系统删除画布引用但保留素材库原文件，除非用户另行删除素材

#### Scenario: 框选多个对象并编辑
- **WHEN** 用户使用选择工具在画布空白区域拖出框选矩形
- **THEN** 系统选中相交的可见对象，并允许批量变换、复制或删除

#### Scenario: 绘制和显隐
- **WHEN** 用户使用画笔绘制或切换某图层的可见状态
- **THEN** 系统将笔迹作为可编辑画布对象保存，并按图层状态显示或隐藏对象

#### Scenario: 调节视图缩放
- **WHEN** 用户使用画布缩放控件选择缩放步进或恢复 100%
- **THEN** 系统按所选比例缩放画布视口，并同步更新缩放百分比

#### Scenario: 绘制时工具栏保持可见
- **WHEN** 用户在画布上绘制或浏览器可视高度变化
- **THEN** 画布工具栏仍固定在可视画布顶部且可操作

#### Scenario: 从单张图片开始 AI 对话
- **WHEN** 用户选中一张画布图片并提交图片专属的 AI 修改请求
- **THEN** 系统自动将该图片作为当前请求附件并在 Agent 面板展示执行进度

#### Scenario: 设置对象颜色
- **WHEN** 用户选中可配色对象并从对象工具条选择颜色
- **THEN** 系统将颜色应用于所有选中对象并纳入撤销历史

#### Scenario: 从素材卡片直接添加
- **WHEN** 用户在素材库卡片上点击“添加到画布”
- **THEN** 系统将素材插入进入素材库前的画布并返回该画布
- **AND** 保留离开画布前的对象状态和可撤销操作历史

### Requirement: 画布文档持久化与恢复
系统 MUST 保存画布文档、版本号和 schema version，并允许所有者恢复最近一次成功保存的状态。

#### Scenario: 重新打开画布
- **WHEN** 用户重新打开其已保存画布
- **THEN** 系统返回可恢复的文档内容、revision 和视口

### Requirement: 自动保存与失败恢复
系统 MUST 在画布变更后自动提交保存，并在网络或服务错误时保留未保存内容和重试入口。

#### Scenario: 自动保存成功
- **WHEN** 用户编辑且保存请求成功
- **THEN** 系统持久化最新文档并显示新的 revision 与更新时间

#### Scenario: 自动保存失败
- **WHEN** 保存请求失败
- **THEN** 系统保留浏览器当前文档并显示可重试的未保存状态

### Requirement: 旧版本写入保护
系统 MUST 检查保存请求的 base revision，防止旧标签页或设备静默覆盖更新版本。

#### Scenario: revision 已过期
- **WHEN** 保存请求的 base revision 小于服务端当前 revision
- **THEN** 系统拒绝覆盖并返回当前版本信息及冲突恢复选项

### Requirement: 用户操作撤销与恢复
系统 MUST 允许用户撤销和恢复有记录的画布操作批次。

#### Scenario: 撤销本人操作
- **WHEN** 用户撤销最近的可逆操作批次
- **THEN** 系统恢复该批次之前的个人画布状态并自动保存

#### Scenario: 恢复已撤销操作
- **WHEN** 用户恢复先前撤销的操作
- **THEN** 系统重新应用对应变更并自动保存
