# Spec Delta

## Purpose

定义用户身份、账户生命周期和个人项目访问规则，确保画布、素材及 Agent 配置只能由其所有者访问。

## ADDED Requirements

### Requirement: 用户名和密码注册
系统 MUST 支持用户仅以唯一用户名和密码注册，不要求邮箱或邮箱验证。

#### Scenario: 新用户注册
- **WHEN** 新用户提交可用用户名和符合规则的密码并接受服务条款
- **THEN** 系统创建可登录账户，并保存经过安全哈希处理的密码

### Requirement: 登录、退出和账户安全
系统 MUST 以服务端会话保护用户数据，并支持使用用户名和密码登录及主动退出。

#### Scenario: 有效用户登录
- **WHEN** 用户提交正确的用户名和密码
- **THEN** 系统建立安全会话并允许访问其个人项目

#### Scenario: 用户退出或会话过期
- **WHEN** 用户主动退出或会话失效
- **THEN** 系统撤销会话并要求重新登录后访问受保护数据

### Requirement: 密码恢复边界
MVP MUST NOT 收集邮箱或提供邮箱找回流程；MVP 不承诺忘记密码后的自助恢复。

#### Scenario: 忘记密码
- **WHEN** 用户未登录并请求找回密码
- **THEN** 系统说明当前版本不支持自助恢复，且不声称已发送重设链接

### Requirement: 自助账户管理
系统 MUST 允许用户修改密码和注销账户，无需平台管理员后台。

#### Scenario: 修改密码
- **WHEN** 已登录用户通过当前密码校验后提交新密码
- **THEN** 系统保存变更并显示成功状态

#### Scenario: 注销账户
- **WHEN** 用户再次确认注销
- **THEN** 系统撤销其所有会话，并按公布的数据保留策略处理其账户及个人项目

### Requirement: 用户资源所有权隔离
系统 MUST 将项目、画布、图片素材和模型配置绑定到明确的用户所有者，并在读取和修改时校验所有权。

#### Scenario: 用户读取自己的资源
- **WHEN** 已登录用户请求个人项目、画布、素材或 Agent 配置
- **THEN** 系统只返回归属当前用户的数据

#### Scenario: 用户尝试读取他人资源
- **WHEN** 用户请求不属于自己的项目或其下资源
- **THEN** 系统拒绝访问且不泄露资源内容

### Requirement: 个人项目管理
系统 MUST 允许用户创建、查看、重命名和删除自己的项目与画布。

#### Scenario: 创建项目
- **WHEN** 已登录用户提交有效项目名称
- **THEN** 系统创建项目并将其所有者设为当前用户

#### Scenario: 删除项目
- **WHEN** 用户删除自己的项目
- **THEN** 系统按项目数据保留规则处理其画布，并保留仍被引用的个人素材
